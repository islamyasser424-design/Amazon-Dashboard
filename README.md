# 🚀 Amazon Supply Chain Analytics Dashboard

An interactive, end-to-end Business Intelligence project built using Power BI to explore the supply chain domain, focusing on financial performance and operational efficiency to support data-driven decision-making.

## 📊 Dashboard Insights & Overview
The report is structured into dynamic sections to provide comprehensive operational and financial visibility:

* **Home Page:** A clean, professional landing page ensuring smooth and intuitive navigation across report sections.
* **Overview Page:** Analyzes total revenue ($577.60K), total products sold (46K), profit margin (99.09%), profit ($572.32K), product categories, and geographical locations across key Indian markets (Mumbai, Kolkata, Chennai, Bangalore, and Delhi).
* **Logistics Performance:** Tracks average shipping cost ($5.5481), average shipping time (5.75), average stock level (47.77), total order quantity (5K), supplier lead times, performance scores, production volumes, and transportation modes (Road, Rail, Air, and Sea).

## 🛠️ Technical Implementation & Architecture
* **Data Cleaning & Transformation (Power Query):** Handled missing values, standardized data structures, and validated data types to ensure complete accuracy.
* **Data Modeling:** Constructed an optimized relational data model with proper relationships between tables to improve analysis consistency and report performance.
* **DAX & KPI Analysis:** Created dynamic measures to track key operational and financial metrics, including Revenue & Profit, Profit Margin, Shipping Cost, Lead Time, Inventory Levels, and Supplier Performance.

## ⚙️ Key Features
* **Interactive Slicers:** Enabled dynamic filtering for real-time analysis across all report elements.
* **Custom Navigation:** Designed a seamless user experience for smooth transitions across dashboard sections.
* **Actionable Visuals:** Delivered data-driven insights through interactive charts and performance summaries.
